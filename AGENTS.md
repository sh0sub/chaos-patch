# Chaos Patch agent rules

- Use this Codex thread for the project from implementation through submission. Do not fork the thread.
- Before project work, read `docs/submission-evidence.md` and suggest a screenshot or recording whenever a listed evidence milestone is reached.
- Keep raw captures local under ignored directories. Never commit secrets or unredacted personal information.
- Treat the repository documentation and the Twitch — Chaos Patch artifact plan as the project source of truth.
- Add or update focused tests before each behavior change, and do not start the next task until they pass.
- Run integration tests whenever several completed behaviors form a coherent user flow.
